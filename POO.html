💻 Programación Orientada a Objetos

Conceptos Básicos Explicados de Forma Simple

1¿Qué es una CLASE?

📋 Definición:

Una clase es como un molde o plantilla que define las características (atributos) y comportamientos (métodos) que tendrán los objetos creados a partir de ella.

🍪

Piensa en un molde de galletas

El molde define la forma, pero no es la galleta en sí

class Persona { // Atributos (características) nombre: string; edad: number; constructor(nombre: string, edad: number) { this.nombre = nombre; this.edad = edad; } saludar(): string { return "Hola, soy " + this.nombre; } }
  • Define la estructura de los objetos
  • Contiene atributos (datos) y métodos (funciones)
  • Es reutilizable para crear múltiples objetos

2¿Qué es un OBJETO?

📦 Definición:

Un objeto es una instancia concreta de una clase. Es algo real y específico creado usando el molde (clase).

👤

De la clase Persona creamos objetos reales

Juan (25 años) y María (30 años) son objetos diferentes de la misma clase

const persona1 = new Persona("Juan", 25); const persona2 = new Persona("María", 30); persona1.saludar(); // "Hola, soy Juan" persona2.saludar(); // "Hola, soy María"

CLASE

Es abstracta (el molde)

Define la estructura

OBJETO

Es concreto (la galleta)

Tiene valores específicos

3¿Qué es la HERENCIA?

🧬 Definición:

La herencia permite que una clase herede atributos y métodos de otra clase. La clase hija obtiene todo de la clase padre y puede agregar sus propias características.

👨‍👦

Como la herencia familiar

Un hijo hereda características de sus padres, pero también tiene las suyas propias

class Estudiante extends Persona { carrera: string; constructor(nombre: string, edad: number, carrera: string) { super(nombre, edad); this.carrera = carrera; } estudiar(): string { return "Estudiando " + this.carrera; } }
  • Permite reutilizar código
  • Crea relaciones "es un" (Estudiante ES UNA Persona)
  • La clase hija puede extender funcionalidad

4¿Qué es una CLASE ABSTRACTA?

🚫 Definición:

Una clase abstracta es una clase que NO se puede instanciar directamente. Solo sirve como base para otras clases y define métodos que las clases hijas DEBEN implementar.

🐾

Concepto de "Animal"

No existe un "animal" genérico. Existen perros, gatos, etc. pero no puedes crear "un animal" sin más.

abstract class Animal { nombre: string; constructor(nombre: string) { this.nombre = nombre; } abstract hacerSonido(): string; } class Perro extends Animal { hacerSonido(): string { return "¡Guau guau!"; } } class Gato extends Animal { hacerSonido(): string { return "¡Miau miau!"; } }
  • No se puede instanciar directamente
  • Define estructura común para clases hijas
  • Obliga a implementar ciertos métodos

5¿Qué es el POLIMORFISMO?

🎭 Definición:

Polimorfismo significa "muchas formas". Es la capacidad de diferentes clases de responder al mismo método de manera diferente.

🔊

Mismo método, diferentes resultados

Todos los animales "hacen sonido", pero cada uno lo hace diferente

const animales: Animal[] = [new Perro("Firulais"), new Gato("Michi")]; animales.forEach(animal => { console.log(animal.hacerSonido()); }); // ¡Guau guau! // ¡Miau miau!
  • Mismo método, diferentes implementaciones
  • Permite código más flexible y extensible
  • Facilita agregar nuevos tipos sin cambiar código existente

6¿Qué es una INTERFACE?

📜 Definición:

Una interface es un contrato que define QUÉ métodos debe tener una clase, pero no CÓMO implementarlos.

✈️

Contrato de "poder volar"

Tanto un pájaro como un avión pueden volar, aunque son muy diferentes

interface Volador { volar(): string; aterrizar(): string; } class Pajaro implements Volador { volar() { return "Batiendo las alas"; } aterrizar() { return "Posándose en una rama"; } } class Avion implements Volador { volar() { return "Impulsado por motores"; } aterrizar() { return "Aterrizando en pista"; } }
  • Define un contrato que las clases deben cumplir
  • Permite que clases diferentes compartan comportamientos
  • Una clase puede implementar múltiples interfaces

7¿Qué es el ENCAPSULAMIENTO?

🔒 Definición:

El encapsulamiento es proteger los datos internos de una clase y controlar cómo se accede a ellos mediante métodos públicos.

🏦

Como una cuenta bancaria

No puedes cambiar el saldo directamente, solo a través de operaciones controladas

class CuentaBancaria { private saldo: number; constructor(saldoInicial: number) { this.saldo = saldoInicial; } getSaldo(): number { return this.saldo; } depositar(cantidad: number): void { if (cantidad > 0) this.saldo += cantidad; } retirar(cantidad: number): boolean { if (cantidad > 0 && cantidad <= this.saldo) { this.saldo -= cantidad; return true; } return false; } }

🔓 public

Accesible desde cualquier lugar

🔒 private

Solo accesible dentro de la clase

🔐 protected

Accesible en la clase y sus hijas
